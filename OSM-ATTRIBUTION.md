# Guangzhou routing graph data

This repository publishes versioned Valhalla graph tiles derived from OpenStreetMap data for the PeiXiu Guangzhou motorcycle routing MVP.

- Source: https://download.geofabrik.de/asia/china/guangdong.html
- License: OpenStreetMap data is available under the Open Database License (ODbL).
- Each graph manifest records the source URL, source checksum, clip bounds, graph version, and tile checksums.
- The graph is an auxiliary routing reference. It is not a legal or safety guarantee.

OpenStreetMap contributors: https://www.openstreetmap.org/copyright
